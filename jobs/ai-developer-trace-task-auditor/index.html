Detailed Job Description & Core Audit Responsibilities

For software developers looking to supplement their income, transition into high-paying AI alignment consulting, or take control of their working hours, understanding the core responsibilities of the AI Developer Trace Task Auditor role is critical. This position demands a sharp eye for software correctness, a deep understanding of full-stack or backend architecture, and the analytical capacity to dissect multi-step engineering sessions.

Key Responsibilities:

  • Trace Evaluation: Review and audit the quality, accuracy, and logic correctness of AI-assisted software development traces used to train and evaluate frontier AI lab models.
  • Workflow & Reasoning Assessment: Judge end-to-end coding sessions produced with AI developer tools, analyzing whether the model selected sound architectural patterns, effective debugging strategies, and logical problem-solving trajectories.
  • Rubric-Based Feedback: Provide clear, structured, and actionable written feedback based on strict evaluation rubrics to align future AI coding generations with human software engineering standards.
  • Code Correctness Verification: Inspect code across diverse backend and full-stack environments to catch logical errors, security oversights, and anti-patterns introduced during automated coding workflows.

Candidate Qualifications: What It Takes to Qualify

Because these evaluations directly influence the capabilities of next-generation foundational coding models, the qualification requirements target experienced, hands-on software professionals rather than entry-level hobbyists.

Basic Qualifications (Must-Have):
  • 3+ Years Professional Software Development: Proven, hands-on experience building, shipping, and maintaining production-grade software applications.
  • AI Coding Tool Familiarity: Practical, day-to-day experience using AI-assisted coding tools and agentic or spec-driven workflows such as Cursor, GitHub Copilot, Claude Code, or similar environments.
  • Debugging & Code-Reading Mastery: Strong code-reading capabilities and sophisticated debugging skills across complex full-stack or backend systems.
  • Trajectory Analysis: Demonstrated ability to evaluate multi-step coding sessions, tracing how a developer or AI agent progressed from prompt to final implementation.

Preferred Qualifications (Nice-to-Have): Experience with specialized development tools like Kiro or Amazon CodeCatalyst, prior professional experience evaluating or grading AI-generated code, and active contributions to developer tooling ecosystems.
