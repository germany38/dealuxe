About the Role: Building the Next Generation of Dialog Agents

As an LLM Java Developer with Turing, your primary focus will be collaborating on the definition, design, and delivery of new features for next-generation dialogue agents. These systems have wide-ranging applications across education, enterprise workflows, and complex problem-solving. This position offers an exciting opportunity for senior engineers eager to operate at the bleeding edge of artificial intelligence.

What Your Day-to-Day Looks Like

Your responsibilities go far beyond traditional coding. You will actively participate in training and evaluating how AI models process, reason about, and generate complex Java code and technical logic:

  • Model Training & Optimization: Design, develop, and maintain efficient, high-quality code to train and optimize advanced AI models.
  • Rigorous Evals & Benchmarking: Conduct evaluations to benchmark model performance, analyzing results for continuous improvement.
  • Expert Response Ranking: Evaluate and rank AI model responses across diverse technical domains, ensuring strict alignment with predefined criteria.
  • Supervised Fine-Tuning (SFT): Lead efforts in SFT by creating and maintaining high-quality, task-specific datasets.
  • RLHF Collaboration: Work alongside researchers and annotators to execute Reinforcement Learning with Human Feedback and refine reward models.
  • Peer Reviews: Conduct thorough peer reviews of code and documentation, providing constructive feedback and identifying areas for improvement.

You Are a Perfect Fit If You Possess:

Required Skills & Qualifications:

  • Technical Foundation: Bachelor’s or Master’s degree in Engineering, Computer Science, or equivalent professional experience.
  • Java Mastery: Deep proficiency with Java syntax, conventions, and scalable backend architecture.
  • Modularity & Security: Demonstrable experience developing web applications using modular development with a strong focus on code readability, security, and stability (testing).
  • Quality Assurance: Prior software Quality Assurance and Test Planning experience is considered a strong plus.
  • Communication: Excellent spoken and written English communication skills.
