About Turing: Powering the Human Intelligence Layer for AI

Role Overview: Senior Software Engineer – LLM Evaluation

As an LLM Evaluation Engineer, your primary objective is to create cutting-edge evaluation tasks and training datasets that challenge and refine large language models. You will work side-by-side with leading AI researchers to evaluate how artificial intelligence models handle complex software engineering tasks, debug code, and adhere to industry best practices.

Core Technical Stack & Languages:

  • Languages: Python, JavaScript (including ReactJS), C/C++, Java, Rust, and Go.
  • Focus Areas: Full-stack architecture, API design, code debugging, security auditing, and automated verification.

What Does Day-to-Day Life Look Like?

The daily workflow in this role is intellectually stimulating, dynamic, and deeply technical. Far from routine coding, your responsibilities span the full breadth of the software development lifecycle:

  • AI Model Training Initiatives: Actively curate complex code examples, build pristine reference solutions, and correct code across Python, JavaScript/ReactJS, C/C++, Java, Rust, and Go.
  • Code Critique & Refinement: Evaluate and refine AI-generated code to ensure it meets rigorous standards of efficiency, scalability, and maintainability.
  • Cross-Functional Collaboration: Partner with research scientists to enhance AI-driven coding solutions against rigorous industry performance benchmarks.
  • Agent Construction: Build specialized verification agents capable of auditing code quality and detecting subtle error patterns in model outputs.
  • Lifecycle Simulation: Hypothesize on every phase of the software engineering lifecycle—prototyping, architecture design, API design, production implementation, launch, experimentation, monitoring, and operational maintenance—evaluating how well models navigate each stage.
  • Automated Verification: Design sophisticated verification mechanisms that automatically test and validate solutions to intricate software engineering problems.

You Are a Perfect Fit If You Possess:

Turing maintains exceptionally high standards to ensure that its AI training data matches elite enterprise quality. Candidates must demonstrate:

  • Several years of professional software engineering experience, including 2+ years of continuous full-time experience at a top-tier product company (such as Google, Stripe, Amazon, Apple, Meta, Netflix, Microsoft, Datadog, Dropbox, Shopify, PayPal, or IBM Research).
  • Deep, demonstrable expertise in building full-stack applications and deploying scalable, production-grade software using modern languages and frameworks.
  • A comprehensive understanding of software architecture, design patterns, advanced debugging techniques, and code review best practices.
  • Exceptional oral and written communication skills, enabling you to articulate clear, structured evaluation rationales for model behaviors.

Perks and Engagement Details

This engagement is structured for top-tier professionals who demand autonomy, flexibility, and high-impact work:

  • Engagement Type: Remote Contractor (Independent contractor status).
  • Commitment Flexibility: Minimum of 10 hours per week, scaling up to 40 hours per week based on your availability and project scope (requires partial PST overlap).
  • Duration: 1-month initial engagement starting next week, with strong potential for long-term extensions based on performance and fit.
  • Global Impact: Direct collaboration with frontier AI labs, positioning you at the forefront of the generative AI revolution.
