Detailed Job Description & Core Responsibilities

This initiative is part of an ambitious new benchmark for scientific computing (Sci Code). As a domain expert, your mission is to design original, highly complex, and executable research problems that today's frontier models cannot solve. You will bridge the gap between theoretical chemistry, programming, and cutting-edge machine learning development.

Key Responsibilities & Workflow:

  • Material Sourcing: Source your own advanced material from published peer-reviewed papers, Kaggle datasets, open-source repositories, or meticulously engineered chemical scenarios.
  • Scientific Prompt Authoring: Craft detailed, precise scientific coding prompts based on your sourced input data and domain equations.
  • Grading Criteria Design: Build robust grading logic and test suites that definitively validate whether an AI-generated solution is correct.
  • Model Calibration: Benchmark and calibrate against frontier models, ensuring tasks ship only when state-of-the-art models fail more often than they succeed.
  • Version Control Workflow: Engage in a pull-request workflow utilizing Git, GitHub, and Docker, passing through automated quality checks for all submitted evaluation tasks.

Candidate Qualifications & Technical Requirements

Because these challenges are designed to stump state-of-the-art neural networks, the bar for entry is intentionally high. Applicants must demonstrate extensive academic pedigree coupled with hands-on coding proficiency.

Mandatory Requirements:
  • Academic Credentials: PhD in Chemistry, Physical Chemistry, Theoretical Chemistry, Computational Chemistry, or a closely related scientific discipline.
  • Subdomain Depth: Demonstrated depth and expertise in both quantum chemistry and computational chemistry subdomains.
  • Programming Proficiency: Working proficiency in Python, R, or another relevant programming language specifically tailored for scientific computing and data analysis.
  • Technical Tools: Comfort navigating Git/GitHub repositories and executing code containers within Docker environments.

Preferred Qualifications: Proven record of publications in peer-reviewed scientific journals and prior experience in scientific software development or research engineering.
