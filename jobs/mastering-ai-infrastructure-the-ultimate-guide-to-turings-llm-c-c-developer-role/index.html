The Role: LLM C/C++ Developer

This engagement is tailor-made for systems engineers who want to bridge traditional low-level programming with state-of-the-art machine learning. You will work alongside cross-functional teams on the definition, design, and delivery of advanced backend features that empower conversational AI models.

Key Role Responsibilities:

  • Code Review & Validation: Rigorously review code and solutions generated by AI systems, ensuring absolute adherence to enterprise quality standards and software best practices.
  • Complex Problem Solving: Utilize deep expertise in C and C++ programming to resolve intricate coding bottlenecks arising during AI validation cycles.
  • Workflow Management: Organize development lifecycles, manage project priorities, and establish precise goals and deadlines.
  • Repository Contribution: Proactively identify and improve public GitHub repositories (working extensively with codebases exceeding 50K+ lines of code) by developing features and refactoring legacy code.
  • Collaborative Leadership: Inspire cross-functional teams, foster a culture of continuous technical improvement, and provide constructive code feedback.

You Are an Ideal Fit If You Possess:

  • A Bachelor’s or Master’s degree in Computer Science, Engineering, or equivalent practical experience.
  • In-depth mastery of C and C++ programming languages paired with rigorous software development discipline.
  • Demonstrated leadership capabilities, ideally with experience guiding small groups of software engineers.
  • Prior exposure to AI systems, code-generation tools, or public GitHub contributions.
  • Exceptional written and verbal communication skills in English, alongside strong strategic and critical thinking abilities.

What a Day-to-Day Looks Like

Your daily routine centers around analytical precision and architectural oversight. You will spend time examining AI-synthesized code outputs, verifying correctness and execution efficiency, and mapping out structural improvements. Because you are collaborating closely with researchers and developers, your insights directly dictate how reliably LLMs handle complex system logic.
