Detailed Job Description & Core Responsibilities

For research scientists, computational biologists, and academic professionals looking to transition into high-impact AI training and evaluation, understanding the core scope of this project is essential. The objective is to design original computational problems that challenge current state-of-the-art models, helping labs measure true scientific reasoning capabilities.

Key Responsibilities Include:

  • Material Sourcing: Source original, high-level scientific material from published peer-reviewed journals, Kaggle datasets, open-source repositories, or meticulously designed experimental scenarios.
  • Scientific Prompt Authoring: Write sophisticated, precise scientific prompts based on the gathered input material, focusing on subdomains such as ecology, biochemistry, and genetics.
  • Grading Criteria Development: Build rigorous, automated grading and evaluation criteria that precisely define correct computational and biological outcomes.
  • Model Calibration: Benchmark and calibrate tasks against frontier LLMs and AI models—ensuring a task only ships when current advanced models fail it more often than they succeed.
  • Code Integration: Operate within modern developer workflows, utilizing Git/GitHub and executing code in Docker environments through structured pull-request workflows with automated quality checks.

Candidate Qualifications & Professional Requirements

Because these benchmarks serve as rigorous stress-tests for frontier AI systems, the qualifications demanded are suitably elite, ensuring that only true experts contribute to the datasets.

Must-Have Requirements:
  • Academic Credentials: PhD (or Master's with equivalent extensive experience) in biology, biological sciences, biochemistry, genetics, ecology, or a closely related field.
  • Subdomain Depth: Demonstrated depth and expertise in at least two key subdomains: ecology, biochemistry, or genetics.
  • Coding Proficiency: Working proficiency in Python, R, or another relevant programming language tailored for scientific computing and data analysis.
  • Technical Stack Familiarity: Comfortable working with Git, GitHub, and running computational code within Docker containers.
  • Research Rigor: Strong background in analyzing complex datasets, handling biological software packages, and translating physical experiments into computational models.

Preferred Qualifications: Proven publication record in peer-reviewed scientific journals; prior software engineering experience in scientific research settings.
