Comprehensive Job Description & Core Responsibilities

For automation specialists, instrumentation experts, and hardware test engineers looking to apply their practical skills to advanced technical architectures, understanding the daily scope of this role is essential. The position involves designing robust testing ecosystems, building automated measurement scripts, and analyzing hardware responses under various operational conditions.

Key Responsibilities Include:

  • Automated Test System Design: Design, build, and implement automated test systems, rigorous procedures, and repeatable test sequences for diverse electrical and electronic hardware.
  • Instrument Integration: Seamlessly integrate laboratory test instruments, high-speed data acquisition (DAQ) systems, and hardware interfaces to fully automate electrical measurements.
  • Script & Framework Development: Develop clean, efficient test scripts, comprehensive automation frameworks, and robust data analysis workflows using standard engineering languages.
  • Comprehensive Testing Execution: Perform functional, performance, validation, regression, and Hardware-in-the-Loop (HIL) testing where applicable to ensure system stability.
  • Failure Analysis & Troubleshooting: Analyze complex test results, troubleshoot hardware anomalies, debug test setups, and pinpoint the root causes of performance failures.
  • Methodology Validation: Review, audit, and validate test methodologies, execution results, and technical approaches against strict engineering project specifications.

Candidate Qualifications & Professional Requirements

Because these projects dictate the structural integrity and performance validation of next-generation hardware and AI-adjacent technology systems, applicants must demonstrate significant hands-on technical proficiency.

Must-Have Requirements:
  • Professional Background: Proven industry experience as an Electrical Test, Test Automation, Electrical, or Hardware Test Engineer.
  • Educational Foundation: Bachelor’s, Master’s, or PhD degree in Electrical Engineering, Electronics, Instrumentation, Mechatronics, or a closely related technical field.
  • Practical Experience: Demonstrated track record in developing or executing automated electrical test systems and working directly with advanced laboratory instrumentation.
  • Programming Proficiency: Strong command of Python, MATLAB, LabVIEW, C/C++, or equivalent engineering scripting languages.
  • Protocol Familiarity: Experience with test automation, data acquisition, and instrument-control protocols including SCPI, GPIB, USB, Ethernet, CAN, or RS-232/485.
  • Documentation Skills: Ability to accurately interpret complex electrical schematics, strict test specifications, and technical documentation.

Preferred Qualifications: Hands-on experience with Automated Test Equipment (ATE), custom test benches, National Instruments (NI) hardware, TestStand, PXI/PXIe systems; familiarity with HIL/SIL and Python-based regression suites; and background testing power electronics, batteries, electric vehicles (EVs), or motors.
