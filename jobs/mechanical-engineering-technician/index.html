Core Responsibilities & Technical Deliverables / Responsabilidades Principales y Entregables

English
  • Workflow Authoring: Design authentic technician tasks covering test setup, instrumentation, data collection, and failure diagnosis.
  • Dataset Synthesis: Construct technical datasets including test logs, calibration records, sensor outputs, and failure reports from real lab scenarios.
  • Solution Pathways: Define accurate diagnostic steps, test data interpretations, and recommended actions.
  • Grading Rubrics: Build rigorous, 35+ item evaluation rubrics assessing instrumentation logic and failure analysis.
  • Precision Documentation: Record detailed technical procedures, observations, and diagnostic findings with absolute clarity.
Español
  • Creación de Flujos: Diseñar tareas técnicas auténticas que cubran configuración de pruebas, instrumentación y diagnóstico.
  • Síntesis de Datos: Construir conjuntos de datos técnicos que incluyan registros de pruebas, calibración y salidas de sensores.
  • Vías de Solución: Definir pasos diagnósticos precisos, interpretaciones de datos y acciones recomendadas.
  • Rúbricas de Evaluación: Desarrollar rúbricas rigurosas de más de 35 elementos para evaluar la lógica de instrumentación.
  • Documentación de Precisión: Registrar procedimientos técnicos detallados y hallazgos diagnósticos con claridad absoluta.
