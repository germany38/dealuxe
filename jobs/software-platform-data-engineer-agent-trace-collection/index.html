About Turing

About the Role

This high-visibility engagement challenges an experienced engineer to build the technical implementation of an advanced tracing system. Specifically, you will capture GitHub Copilot CLI agent traces across developer machines, centralize privacy scrubbing within Azure, and serve a fully sanitized, queryable dataset for review. You will own the pipeline end-to-end—from the endpoint capture script to Azure ingestion, scrubbing, and viewer visualization.

Are You a Fit?

You are an ideal match for this role if you can take a comprehensive written design and ship a fully functional production pipeline mostly on your own. Crucially, you treat data privacy as a hard, uncompromising requirement rather than an afterthought.

What Your Day-to-Day Looks Like

  • OpenTelemetry Capture Path: Stand up endpoint environment variables, `.bashrc` setups, OTLP exports, and complete collector pipelines (receivers to processors to exporters).
  • Central Ingestion & Privacy Scrubbing: Build the central ingestion and PII/secret detection-and-redaction block in Azure before any data ever reaches human reviewers.
  • Sanitized Stores & Trace Viewer: Wire up secure sanitized data stores and a read-only trace viewer featuring seamless task-to-session-to-trace correlation.

Required Skills & Experience

  • Education: Bachelor’s degree in Computer Science, Engineering, or a related field—or equivalent practical experience.
  • Engineering Tenure: 5+ years of professional experience in software, platform, or data engineering, successfully shipping production systems.
  • Cloud & Observability: 3+ years hands-on with Azure (or a comparable major cloud with clear transfer to Azure PaaS), including 2+ years building observability or telemetry pipelines with direct OpenTelemetry experience (OTLP, collectors, spans/traces, semantic conventions).
  • Azure PaaS Stack: Proficiency with Container Apps/AKS, API Management, ADX/Kusto or App Insights, ADLS Gen2/Blob, Key Vault, and Entra ID.
  • Programming & Scripting: Solid background in Python or Node.js, combined with robust Bash scripting capabilities.
  • Data Privacy & Security: Practical background in PII and secret scrubbing (using regex, entropy analysis, and tokenization), alongside core cloud security and data pipeline fundamentals (RBAC, private networking, audit).

Nice-to-Have Qualifications

  • Grafana and telemetry-backend setup experience.
  • LLM-agent or Generative AI observability exposure.
  • Cross-cloud identity federation expertise (Azure AD/Entra ID ⇄ GCP IAM).

Engagement Details
